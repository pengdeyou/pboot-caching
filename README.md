# pboot-caching

A fork of the [Pboot-Cache](https://github.com/thadeusb/pboot-cache) extension
which adds easy cache support to Pboot.

## Installing

You can install the extension with the following commands:

```text
$ pip install -U pboot-caching
```

or alternatively with uv:

```text
$ uv add pboot-caching
```

pboot-caching 2.5.0 supports Python 3.11+.
